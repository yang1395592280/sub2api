# 检测记录与质量监控交互改进

## 范围与验收
- 独立检测记录页及侧栏/监控入口：按时间倒序、服务端分页，支持时间、来源组、账号/模型和结果筛选，展示回答详情。
- 监控按账号与来源组聚合模型；中文状态、具体组名、分页、显式时间线与历史操作。
- 配置采用分区与可搜索分组选择，保留每账号两模型；普通 OpenAI 业务组允许手动和定时检测。
- 控制边界：仅自动不降智来源可参与调度控制。普通组检测证据不影响固定组业务请求。

## 影响与风险
- provider inventory/Resolve → 策略创建、预览、reconcile、检测执行；针对来源组权限做后端回归。
- Policy JSON 增加名称与控制能力字段，旧文档兼容；无数据库结构迁移。
- runs HTTP/repository 增量筛选 → 新 records 页与原有时间桶下钻兼容，限制日期范围、参数化 SQL。
- route/sidebar/i18n → 监控/配置/历史三个入口，精确菜单匹配。
- 本次仅本地实现，不发布、不执行生产配置变更或真实账号请求。
