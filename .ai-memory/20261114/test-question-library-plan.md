## 决策与边界

选择扩展现有队列，避免建立第二套消费者与重复付费并发控制。新题目入队从数据库读取并锁定有效题目，记录内容与答案快照；原单 prompt API 保持兼容。

保留全局三路生成并发、500 秒超时与当前权限边界。新维护接口限定完整管理员；手动批测的选题偏好按管理员和测试类型隔离，成功创建任务后与入队同事务保存。分组配置独立持久化。

采用关联 ID 数组保存有界选择（最多 20），避免额外关系模型；历史题目引用不使用级联删除，停用代替删除。撤销条件：将来需要题库共享权限或高数量排序时重新设计关联模型。

## 需求映射与阶段

1. 数据与队列：新增题库/偏好、历史快照、分组选题与间隔约束；默认题与旧自定义分组迁移；实现逐题原子入队、去重与配置复核。出口：仓储测试及 PostgreSQL 集成测试。
2. 服务与 API：维护校验、管理员隔离、兼容旧单题入口、最新批次与批次历史查询。出口：服务和 HTTP 边界测试。
3. 前端入口：维护页/导航、多选器、批量数量与记忆、分组间隔和多选。出口：Vitest、类型检查。
4. 结果呈现：账号列表批次汇总、正确进度、智力题逐题结果/鹈鹕作品卡、历史快照。出口：组件测试及浏览器交互。
5. 交付：构建、diff 自审、文档与迁移回退 SQL、验证证据及会话总结。

## 规划门禁与非功能决策

- A1–A10：需求映射、出口、数据影响、兼容/回退、验证、修改范围、权限输入、原工作区、阶段恢复均已明确。预计约 30–40 个相关文件，只处理本功能。
- B1/B3/B5/B6/B7/B8/B9/B10/B11：新增迁移与独立回退 SQL；活动任务唯一索引；原子偏好保存；旧接口保留；针对性测试；按阶段小批修改；DDL 仅测试数据库；依赖 grep 复核；所有脚本显式工作目录；完成后回读。B2 无新增依赖。B4 不涉及网关热路径，不声明性能提升。
- C1/C2：每阶段或约 5 文件更新检查点，长任务从本文件和 handoff 继续，验证失败只修对应阶段。
- 容量：最多 100 账号、20 题、1000 条/手动批次；题库按类型最多 500；历史分页，摘要不读 HTML 正文。
- 并发/幂等：题目锁与队列插入同事务；唯一键账号/类型/题目；分组 due slot 与任务同事务；沿用跨实例 claim 锁和 3 路并发。
- 重试/降级：不自动重试已发送的付费生成；外部调用超时沿用；题库或偏好加载失败展示错误，可重试，不默默换题。
- 可观测性：沿用分组调度/claim 错误日志，结果保留批次、题目与账号；返回真实创建数量，前端提示跳过记录数。
- 安全：完整管理员维护；不执行用户 HTML；保留现有 sandbox 预览与敏感错误脱敏；SQL 参数绑定。
- 回退：先关闭新定时配置、排空或显式终止多题活动任务，再恢复旧索引/30 分钟约束；保留新增数据。最终 SQL 放 docs 下，不能混入 migration 执行。
- 测试与审查：联动 test-generation + code-review，自行执行；不创建子 agent。没有图谱/新 hook 时以 rg 逐层检查调用链，不引入无关 hooks。
