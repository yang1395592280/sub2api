# 智力题测试与上游费用实施方案

日期：2026-11-13。当前基线：custom-main / fd6b93ec1。
状态：本地实现与验收完成；用户已确认完整实施方案与“Token＋上游费率估算，明确标注估算金额”；开发分支 feature/intelligence-tests-upstream-cost。未提交、合并、推送或部署。

## 用户需求与验收

1. 鹈鹕测试最新结果及详情显示本次消耗的上游余额，历史保留当次费用，不使用本站分组售价。
2. 在账号列表“鹈鹕历史”下增加“智力题历史”，按时间排列数字结果；20 绿色，其他数字红色，请求失败单独显示。详情保留原始回答、模型、时间、耗时与用量。
3. 增加“批量智力题测试”，沿用账号选择、模型选择和任务进度；在“动画预览”后增加智力题结果列，并提供单号重试。
4. 分组管理增加独立智力题测试入口/开关。提案为默认关闭、独立选择模型、每 30 分钟定时执行；用户若只要手动，由分组开关控制可用性则调整实现。

## 已核实的实现边界

- 复用 pelican_test_service、pelican_schedule_service、pelican_test_repo 和 pelican_schedule_repo 的持久队列、并发上限、超时、来源分组快照和重启恢复。
- 在记录与计划中区分测试类型；旧记录和旧配置默认 pelican，按类型筛选最新结果/详情/历史，避免相互覆盖或读错记录。
- 两类任务共享全实例 3 个执行槽；同账号同类型活动任务去重，手动与定时采用一致规则；定时调用前复查组配置及成员状态。
- 智力题固定使用用户提供的中文原题、数量表和“请给出最终答案数字。不要联网。”；不向被测模型提供答案，不附带联网工具。严格解析最终数字，非数字响应保留原文并标记格式异常，不从推理过程随意提取数字。
- 智力题判分只展示结果，不进入旧质量模块的健康评分或调度控制；旧质量模块与新历史相互独立。
- 正确答案 20；离线枚举所有合法糖果数量组合验证最优固定形状取法为圆形 9 颗、五角星形 11 颗。

## 上游费用待选口径

A. 调用前后读取上游余额，保存原始余额、币种、差额和来源；仅同口径成功快照可计算。缺失、不支持、余额增加等情况显示不可获取，不将缺失显示为 0。充值和同 Key/同上游钱包并发消费会影响差额，UI 必须明确这是余额变化，不能冒充逐请求账单。已有探测能力可能读取账户余额，也可能读取 Key 配额，实施前按 provider 校验来源一致性，不混用。

B. 使用实际 Token 和已知上游费率估算，明确标注估算；需要补齐缓存 Token、模型映射及计费档位信息，不能直接套本站分组倍率。缺少可信费率时显示不可获取。

现有 OpenAIUpstreamBalanceService 可探测 sub2api/new-api 余额与倍率，但并未给鹈鹕任务保存逐请求实扣账单。历史任务没有调用前快照，不回填臆测费用。

## 迁移与回退

- 仅新增兼容迁移文件，为测试记录增加类型、判分摘要和费用快照；分组计划按测试类型保存独立配置，并更新相应索引。
- 旧测试类型默认 pelican，新分组智力题配置默认关闭，迁移不自动触发付费调用。
- 迁移必须在隔离测试数据库验证旧记录兼容、唯一约束、读写对称性和任务领取；本次不执行生产迁移或启用生产配置。
- 回退前关闭智力题计划并排空新类型任务；保留新增列和历史。若复用旧队列表，回退版本不能领取/误执行智力题任务，需在实施时给出可执行回退说明。
