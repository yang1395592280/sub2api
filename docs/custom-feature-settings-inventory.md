## 加入社群入口

社群入口必须同时满足以下条件才会显示：

1. 在「二改功能」开启 `join_group_enabled`；
2. 在「通用设置 → 站点配置」填写进群链接，或上传进群二维码/宣传图；
3. 保存详细参数后刷新用户侧页面。

入口已覆盖默认首页、简洁首页和登录后页面头部。配置二维码时点击入口先展示弹窗；有链接时可直接跳转。全屏自定义首页内容由管理员自行接管，不注入站点入口。
