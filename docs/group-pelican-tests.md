# 分组定时鹈鹕测试

本功能按 OpenAI 分组生成鹈鹕骑自行车的 HTML 动画，展示最新结果并保存历史作品。仅记录生成是否成功，不自动评分，也不改变账号优先级、隔离状态、限流状态或调度评分。

## 使用入口

1. 管理员打开 **分组管理**，在需要测试的 OpenAI 分组行点击 **鹈鹕测试**。普通分组、0.1 分组和自动不降智分组都可配置。
2. 打开 **自动生成测试作品**，选择或输入完整模型 ID。可修改生成提示词；默认提示词为“创建一个HTML，内容是绘制一个鹈鹕骑自行车的2D动画，你不需要任何测试”。
3. 保存后首轮通常在一分钟内入队，此后每 30 分钟入队一次。队列繁忙时实际生成时间会延后。每个分组配置一个模型，各账号仍须支持该模型。
4. 打开 **账号管理 → 鹈鹕测试** 列，查看最新状态、时间、模型、耗时和 Token。列表会定期刷新，点击结果可查看动画与原始响应。
5. 点击同列 **鹈鹕历史**，进入该账号的 **鹈鹕作品档案**。作品按最新时间排列，每页 12 条，包含分组定时和原账号页手动测试。点击作品查看动画、提示词、HTML 源码和原始响应，也可下载 HTML。

新分组配置默认关闭。启用会持续消耗上游调用额度；不需要配置旧质量模块的视觉评审账号或私网渲染器。

## 账号范围与执行规则

- 每轮读取当前分组的直接成员，只测试 OpenAI 平台、未删除、状态为 active 且允许调度的账号；不递归展开绑定的内部账号池。
- 同一账号已有排队或运行中的鹈鹕任务时，本轮跳过。手动与定时任务共用此限制；共享账号属于多个启用分组时，也只保留先入队的一个任务，不保证同一时段每个组的模型都会分别执行。
- 所有实例合计最多 3 个鹈鹕生成任务同时运行，任务由数据库领取。保存或修改配置只影响该功能的独立配置，不覆盖原分组设置。
- 真正调用上游前再次检查配置、分组状态、账号状态、成员关系、模型及提示词；条件已变化的排队任务记为失败并写明原因。已经发出的请求不因修改分组配置而撤回。
- 服务重启后继续领取排队任务，不重放正在运行的付费请求。运行超过 10 分钟、排队超过 6 小时的任务会被终结；单次生成上限 500 秒，返回正文上限 1 MiB。
- 定时任务直接使用选定账号，不经网关重新调度。401、429 等结果仅记录本次失败；凭证刷新沿用既有实现。

## 结果与历史

“可预览”表示取得完整 HTML，可在沙箱中查看，**不代表动画质量合格或模型未降智**。无完整 HTML、请求失败分别显示具体状态。Token 未返回时显示“—”。预览隔离后台权限和外部网络，依赖外部 CDN 的作品可能不完整。

历史取消原有“每账号最近 3 条”和“30 天删除”的清理逻辑，完整保留；既往已经删除的记录无法恢复。列表只传摘要，动画和正文按需加载，但完整 HTML 与响应仍占用数据库空间，应监控磁盘与备份容量。来源分组 ID、名称为生成任务入队时的快照，之后重命名或删除组不改写历史归属。

旧质量监控中的糖果/SVG 双检测仍使用其独立记录和保留期，不混入本页面的 HTML 作品历史。

## 旧质量模块总开关

旧 **OpenAI 质量监控 / 检测记录 / 质量检测配置** 已收纳到一级 **质量监控** 菜单。总开关位于 **系统设置 → 二改功能 → 旧版 OpenAI 质量监控总开关**。

升级时默认维持原状态（未配置时开启）。关闭后隐藏旧菜单、禁止旧管理接口、停止旧任务领取和新阶段调用，并停止旧模块的调度干预，已有配置和历史保留；新分组定时鹈鹕测试独立运行。调度缓存通常在 5 秒内刷新；旧在途任务每 15 秒检查并取消，已经发送的上游请求仍可能产生费用。重新开启会恢复原配置的自动化与调度控制，原排队任务仍按有效期处理。

## 迁移、兼容与回退

新增迁移 `backend/migrations/249_group_pelican_tests.sql`：创建独立配置表 `group_pelican_test_schedules`，为 `account_pelican_tests` 增加来源组 ID 和名称字段；旧手动记录默认来源 ID 为 0。迁移不启用任何分组，也不回写已有作品。完整管理员可访问新增接口，受限管理密钥不能修改分组配置或查询账号历史。

发布前备份数据库，在测试环境通过项目正常迁移流程验证后再上线。关闭各分组的测试开关可停止后续调用；回退旧应用时保留新增表、列和历史，不需要立即删除结构。**旧版仍可能执行原有历史清理，因此若要求保留全部作品，应先备份或使用保留该修复的回退版本。**

本次实现只修改本地代码与迁移文件，没有执行生产迁移、部署、真实供应商调用或启用生产配置。
