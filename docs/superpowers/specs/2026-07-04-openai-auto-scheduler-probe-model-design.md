# OpenAI 自动调度检测模型与速度优先级设计

## 背景

当前 OpenAI 自动调度探测模型硬编码为 `gpt-5.4`、`gpt-5.5` 两个模型。调度选择时除请求模型自身状态外，还会检查这两个模型是否存在熔断状态；只要任意一个模型处于有效熔断，当前账号会被整体跳过。

本次需求希望改为后台可配置的单一“自动调度检测模型”，并在所有账号调度状态正常时按速度生成优先级。页面展示、自动探测、熔断过滤和真实调度依据需要保持一致。

## 目标

1. OpenAI 自动调度只探测一个后台可配置模型。
2. OpenAI 自动调度页面支持编辑“检测模型”，页面模型筛选和分组标注默认跟随该配置。
3. 真实账号调度使用配置的检测模型作为健康和速度排序基准。
4. 当账号自动调度状态同级且正常时，按速度优先级排序，速度快的账号优先被选中。
5. 账号管理列表新增一列，展示自动调度状态、速度优先级和最近速度指标。

## 非目标

1. 不做多模型探测配置。
2. 不新增复杂的速度排序策略开关。
3. 不改变账号原有启用、可调度、分组、过期、限流、临时不可调度等基础过滤逻辑。

## 方案

### 配置模型

在 `OpenAIAutoSchedulerSettings` 中新增 `probe_model` 字段。

默认值为 `gpt-5.4`，用于兼容现有页面默认展示。配置为空或全空白时，后端归一化为默认值。

自动探测任务不再返回固定模型数组，而是读取设置中的 `probe_model`，每个启用 OpenAI 自动调度的分组和可调度账号只探测这一个模型。

### 熔断判断

配置的 `probe_model` 是账号级健康判断基准模型。

调度选择时：

1. 读取配置的 `probe_model`。
2. 使用 `probe_model` 查询账号在当前分组下的调度状态。
3. 账号级熔断检查只检查 `probe_model`，不再固定检查 `gpt-5.4`、`gpt-5.5`。

这样可以避免旧双模型逻辑中“任一历史模型熔断导致账号被跳过”的误伤，也保证页面看到的状态和实际调度依据一致。

### 速度优先级

新增速度排序值和展示优先级。速度指标优先使用最近 `last_ttfb_ms`，没有 TTFB 时使用 `last_latency_ms`，仍无样本时视为未知速度。

同状态层级内排序规则调整为：

1. 状态层级优先：`half_open`、`running`、`observing`、`open`。
2. `running` 等正常可调度状态内，已知速度的账号按速度从快到慢排序。
3. 速度相同或未知时，再回退到有效调度分、账号原 `priority`、最近使用时间和原始顺序。

页面展示的速度优先级按当前分组和配置检测模型下的可调度账号计算，`#1` 表示当前筛选范围内速度最快。

### OpenAI 自动调度页面

页面顶部配置摘要增加“检测模型”。

编辑调度配置表单增加检测模型输入项。保存后：

1. 更新后端配置。
2. 模型筛选默认切换到新的 `probe_model`。
3. 左侧分组卡片中的“默认模型”标注改为当前配置模型。

模型筛选仍保留，用于查看历史或手工记录，但默认值和主标注跟随 `probe_model`。

### 账号管理列表

账号列表 DTO 增加 OpenAI 自动调度摘要字段，仅 OpenAI 账号在存在相关分组或检测状态时返回。

摘要内容包括：

1. 调度状态。
2. 速度优先级。
3. 最近 TTFB / 延迟。
4. 检测模型。
5. 最近错误或原因摘要。

前端账号管理新增可切换列“自动调度”，展示状态徽标、速度优先级和最近速度。非 OpenAI 账号或无调度数据时显示 `-`。

## 数据与兼容性

本次优先复用现有设置存储，不新增数据库迁移表结构。

历史 `gpt-5.4`、`gpt-5.5` 探测状态保留用于页面筛选查看，但不再参与账号级熔断过滤，除非它正好是当前配置的 `probe_model`。

## 错误处理

1. 保存空检测模型时后端归一化为默认模型。
2. 手工探测仍要求模型非空，页面默认传当前配置模型。
3. 账号列表摘要加载失败时，不影响账号列表主数据返回；可记录日志并返回空摘要，避免管理页不可用。

## 验证

后端测试：

1. 配置 `probe_model` 后，探测 runner 只提交该模型。
2. 调度选择只因配置模型熔断跳过账号，不再受非配置模型历史熔断影响。
3. 多账号均为 `running` 时，速度更快的账号排序更靠前。
4. 缺少速度样本时排序稳定回退。

前端测试：

1. OpenAI 自动调度设置表单可展示和保存检测模型。
2. 模型筛选和分组标注跟随配置模型。
3. 账号管理表格展示自动调度状态和速度优先级。
