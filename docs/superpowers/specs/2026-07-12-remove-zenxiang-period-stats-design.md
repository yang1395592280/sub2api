# 臻享礼遇统计页精简设计

## 背景

臻享礼遇运维的“数据统计”页会并发请求汇总统计、用户统计、奖品统计、周期统计和授权列表。周期统计需要聚合全量 `usage_logs`，导致页面刷新耗时明显增加。

## 目标

- 删除统计页顶部的汇总指标。
- 删除周期统计表格及按天、按周、按月切换控件。
- 页面不再请求汇总统计和周期统计接口，避免执行对应数据库查询。
- 保留用户统计、奖品统计和授权数据。

## 实现范围

前端 `ZenxiangLiyuAdminView.vue` 删除以下状态和展示逻辑：

- `overview` 汇总指标及平均奖励派生值。
- `periodStats` 周期统计数据。
- `statsPeriod` 周期选择状态及切换逻辑。
- `getOverviewStats()` 和 `listPeriodStats()` 请求调用。

前端 API 方法和后端 API 路由暂时保留，以维持已有接口兼容性。页面不再调用这些接口，因此正常进入或刷新统计页时不会执行对应慢查询。

## 数据流

进入或刷新“数据统计”页时，只并发请求：

1. 指定日期的用户统计。
2. 奖品统计。
3. 用户授权列表。

三个请求全部完成后更新页面现有的用户统计、奖品统计和授权状态。

## 测试与验收

- 组件测试验证进入统计页不会调用 `getOverviewStats()` 和 `listPeriodStats()`。
- 组件测试验证用户统计、奖品统计和授权列表仍会加载。
- 运行相关 Vitest 测试和前端构建。
- 启动页面后确认被标记区域及周期切换控件消失，用户统计和奖品统计正常显示。

## 风险

- 汇总指标和周期统计将不再从管理页面访问，但后端接口仍可被其他客户端直接调用。
- 用户统计仍会聚合指定日期内的 `usage_logs`，数据量较大时仍可能存在一定查询耗时，但不再执行全历史周期聚合。
