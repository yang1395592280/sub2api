# 智力题测试与上游消耗估算

## 使用方式

1. 在账号管理勾选账号，点击 **批量智力题测试**，选择或填写模型 ID 后提交。糖果题固定为用户提供的中文原题，包含数量表及“请给出最终答案数字。不要联网。”，不能修改，也不会附加联网工具。
2. **动画预览** 后面的 **智力题测试** 列展示最新结果、模型、耗时、时间、用量和费用估算；可单独重新测试账号。
3. **鹈鹕历史** 下新增 **智力题历史**。历史按最新记录在前排列，每页 20 次，横向滚动查看。20 为绿色，其他最终整数为红色，× 表示请求失败或回答格式异常，点击可查看原文与费用依据。只接受完整的最终数字回答，不从解释、推理或多数字文本中猜答案。
4. 分组管理中，OpenAI 分组具有独立的 **智力题测试** 入口。默认关闭，可独立设置模型；启用后首轮通常在一分钟内入队，此后每 30 分钟一次。关闭开关不影响手动测试。鹈鹕计划、智力题计划和旧质量模块互相独立。

标准答案为 **20**。因为可按手感选择形状，取 9 颗圆形及 11 颗五角星形能够保证目标；离线枚举所有可行口味/形状组合验证了不存在总数更少的保证策略。标准答案仅用于后端判分和管理页面显示，不发送给被测模型。

## 执行规则

- 复用原有持久队列，所有实例、两类测试合计最多 3 个并发请求。同账号同类型只保留一个活动任务，两个类型互不覆盖。重启不重放已发出的付费请求。
- 定时任务读取分组当前直接成员，仅测试 OpenAI、active 且允许调度的账号；上游调用前重新检查组配置及成员状态。已发出的调用不会因关闭开关撤回。
- 智力题测试只显示本次结果，不影响账号健康、优先级或调度评分。仅完整管理员可使用新增接口，受限管理密钥不可访问。
- 单次请求最长 500 秒，正文上限 1 MiB。历史保留原始回答，不进行自动删除，应按现有备份策略监控数据库容量。

## 费用口径

鹈鹕与智力题的列表、详情均显示 **上游消耗（估算）**，鹈鹕历史卡片也显示当次金额。

使用上游返回的实际输入、输出、缓存 Token，结合执行当时的模型单价、service tier 和上游倍率计算。Gemini 独立返回的 thinking Token 计入输出费用，同时保留原来的可见输出 Token 统计。输入中的缓存部分先扣出，再按缓存价格分类计算，避免重复计费。优先使用响应中的计费模型，否则使用账号模型映射后的模型。

倍率优先使用有效的上游计费声明，并按调用时刻重新计算峰谷倍率；无有效声明时使用余额探测保存的倍率。余额探测的倍率已按充值比例归一化，因此估算余额扣减时需乘回充值比例。本站分组售价和账号销售倍率不参与该估算。

金额、模型与倍率随结果保存，不因之后更改配置而重算。缺少实际用量、可信倍率或可用模型价格时显示 **不可估算**，旧历史不追溯补值；真实零费用和缺失值分别处理，微额不会四舍五入成零。

这是基于本地价格目录与上游倍率的估算，不是逐请求实扣账单。上游自定义模型单价、按次计费、最低扣费、四舍五入和其他优惠可能造成差异。不主动探测调用前后余额，也不额外发送付费调用以计算费用。

## 接口与存储

新增管理员接口：

- `POST /admin/accounts/intelligence-tests`：创建手动批量测试。
- `POST /admin/accounts/intelligence-tests/latest`：查询指定账号的最新摘要。
- `GET /admin/accounts/intelligence-tests/:test_id`：详情。
- `GET /admin/accounts/:id/intelligence-tests`：分页历史。
- `GET/PUT /admin/groups/:id/intelligence-test`：独立分组计划。

现有鹈鹕接口路径保持原样。所有查询按 `test_kind` 隔离，包括详情 ID；客户端不能通过修改请求中的类型读到另一类型的数据或修改另一计划。后台强制使用固定智力题，即使客户端提交其他提示词也不会采用。

迁移 `253_intelligence_tests_and_estimated_cost.sql` 为 `account_pelican_tests` 增加类型、答案及费用快照，为分组计划增加类型。既有记录、计划默认 `pelican`，迁移不启用智力题计划。活动任务唯一键调整为 `(account_id, test_kind)`，计划主键调整为 `(group_id, test_kind)`。

## 升级与回退

**历史数据兼容，旧二进制的 SQL 约束不兼容。** 不要把本次迁移视为可与旧版本混跑的滚动升级：旧版本的 `ON CONFLICT (account_id)` 和 `ON CONFLICT (group_id)` 不再匹配新约束。

发布前先备份数据库及当前应用制品，在测试环境验证正常迁移与新旧历史。正式升级需要停止所有旧实例的任务领取与新建，等待在途请求结束，再按项目正常迁移流程升级全部实例，避免新旧二进制同时操作队列。

优先回退方式是关闭智力题分组计划、停止新建任务，并使用仍支持迁移 253 类型字段与复合约束的修复版本；保留数据库及全部历史，不再触发新类型调用。若必须恢复迁移前的原二进制，应先停止所有实例，恢复发布前数据库备份及对应应用制品；这会丢失升级后产生的数据，需事先导出并核对。不能只替换二进制或直接删除类型字段。

若不能恢复整库，需要另行准备并在备份副本验证专门的降级迁移：完整归档新类型记录及计划、从运行表隔离新类型、恢复旧唯一键和主键，再确认旧任务不会领取智力题记录。该降级迁移未包含在本次实现中，不应临时在生产执行。

本次仅准备本地代码与迁移，没有执行生产迁移、启用生产计划、真实供应商付费调用、提交、推送或部署。
